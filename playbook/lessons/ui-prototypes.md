# UI prototypes and redesigns

## What happened

**Cowork prototype (Mar 2026)**
- 5 PRs in 3 days. Features were added and then removed, e.g. the morning digest was built and then dropped.
- The PRD was written on day 4, after the build.
- Feedback came in by screenshot: "buttons show up on different lines for different cards". These are layout rules that could have been set up front.

**TV remote:** a redesign before "show me designs first" became the rule, then a full simplicity redesign after.

## Rules

1. **PRD before prototype.** One page: who, the jobs, which screens, and what's out of scope. It can be rough, but it comes first.
2. **Show 2–3 options as images first.** Choose, then build.
3. **Set the layout rules once:** consistent card anatomy, fixed button rows, the longest text, empty and error states. Check them with screenshot tests.
4. **Kai screenshots every screen before handing over**, so you never find visual bugs first.
